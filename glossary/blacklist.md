# Blacklist — Términos que no usamos

Lista negra editorial. Estos términos no entran en piezas del Vehemiurgo.
Cuando aparezcan en un input, los reemplazamos por la forma carny correcta.

La razón no es purismo: es que cada uno de estos términos **importa una
gramática que no es la del wrestling** (TV serializada, cómic, fandom geek,
streaming) y la importa silenciosamente. Si los dejamos pasar, perdemos la
sustancia old-school sin darnos cuenta.

---

## Importados de cómic / SF / fandom geek

| Prohibido | Por qué | Reemplazo |
|---|---|---|
| **lore** | El wrestling no tiene "lore". Tiene **historia**, **kayfabe**, **continuidad de booking**, **memoria del público**. | historia / kayfabe / continuidad |
| **canon** | No hay canon en wrestling. Hay decisiones de booking que el público acepta o rechaza. | versión oficial / lo bookeado / lo aceptado |
| **headcanon** | Idem. | interpretación / lectura del fan |
| **easter egg** | El wrestling no esconde guiños para descifrar. **Hace** referencias o las **vende**. | referencia / guiño / homenaje |
| **multiverso** | Categoría ajena al oficio. Dos versiones de un personaje (heel/face, máscara distinta) tienen nombre propio en el oficio. | gimmick alterno / re-debut |
| **villano** | Es **heel**. | heel / rudo |
| **héroe** | Es **face / babyface**. | face / técnico |
| **antihéroe** | Pop-cultural, ajeno. Stone Cold no era "antihéroe": era heel celebrado por contraste con McMahon. | heel celebrado / face con rasgos heel |
| **arc / arco de personaje** | El wrestling no escribe arcos. Escribe **ángulos** y **storylines**. | ángulo / storyline / programa |
| **redemption arc** | Idem. | turn de heel a face / face turn |
| **plot armor** | El "plot armor" en wrestling se llama **push** y es decisión de booking, no narrativa. | push / protección |
| **fan service** (positivo) | Importado de fandom japonés/anime, despoja al gesto carny de su lógica de venta. Si el dream match vendía boletos, era *draw*. Si era guiño barato, era *cheap pop*. | dream match / cheap pop / cumplir un pedido |
| **main character energy** | Lo que describe ese término ya tenía nombre: estar **over como top guy** o **getting the rocket strapped to him**. | top guy / rocket push |
| **side character** | El wrestling no tiene "personajes secundarios". Tiene **mid-card**, **upper-card**, **opener**, **enhancement talent**. | mid-card / opener / etc. |

## Importados de TV serializada / streaming

| Prohibido | Por qué | Reemplazo |
|---|---|---|
| **episodio** | Un Raw no es un episodio. Es un **show**, un **programa**, un **taping**. | show / programa / edición |
| **temporada** / **season** | El wrestling no tiene temporadas. Tiene **builds**, **runs**, **periodos**, **eras**, **ciclos de PPV**. | build / era / periodo |
| **season finale** / **mid-season** | Idem. Si querés decir "el último Raw antes de WrestleMania", se dice **go-home show**. | go-home show / blow-off |
| **showrunner** | El wrestling tiene **booker** o **head booker** o **head of creative**. Showrunner es de TV. | booker / head booker |
| **writers' room** | Tiene **booking team** o **creative team**. La diferencia importa: el writers' room escribe diálogo; el booking team decide quién pierde, dónde y por qué. | booking team / creative team |
| **guion** / **script** | Lo que se "escribe" en wrestling es la **promo** y el **finish**. El match se **bookea** y se **calls** en vivo. | promo / finish / booking |
| **spoilers** (uso ligero) | Concepto no se importa con la lógica de TV. En wrestling, un finish filtrado se "**filtró**" o el resultado del taping se "**leakeó**". Cuidado con la palabra. | resultado filtrado / leak |
| **cliffhanger** | Es **angle abierto** o **hook para el próximo show**. | hook / angle abierto |
| **pilot episode** | No aplica. | debut / primer programa |

## Importados de internet / discurso joven

| Prohibido | Por qué | Reemplazo |
|---|---|---|
| **GOAT** | Adjetivo plano, sin oficio. Decimos por qué fue grande y comparamos. | el más grande de [su rama] / drawing card más grande de [era] |
| **carry** / **carrying** (en sentido gamer) | Confunde con el sentido legítimo del oficio (un veterano *carries* a un joven verde). Si el sentido es el de "cargar el match al hombro" en el sentido gamer, está bien usado. Si es para describir que un talento "carga la promoción solo", decimos top guy / drawing card. | depende del sentido — distinguir |
| **pasivo / activo / soft / hard** (de imageboards) | Despectivo por moda. | (analizar caso por caso, casi siempre cortar) |
| **based** / **cringe** | No editorial. | (cortar) |
| **cope** | Idem. | (cortar) |
| **W / L** (como sustantivo: "fue una W") | Empobrece. | victoria / triunfo / acierto / fracaso |
| **mid** | Idem. Si algo es mediocre, decimos **mediocre**. | mediocre / flojo / sin levantar |

## Marketing y corporativo

| Prohibido | Por qué | Reemplazo |
|---|---|---|
| **content** (a secas) | El wrestling no produce *content*. Produce **shows**, **matches**, **promos**, **angles**, **PPVs**. *Content* es la categoría con la que la industria se desarma a sí misma. | show / programa / pieza |
| **content creator** | (idem cuando se aplica al talento). | luchador / talento / worker |
| **engagement** (como métrica única) | Sin contexto, vacío. Decimos qué métrica concreta. | views / share / rating / buys / interacciones |
| **synergy** | (cortar) | — |
| **audience touchpoints** | (cortar) | — |
| **brand storytelling** (aplicado a wrestling) | El wrestling no es *brand storytelling*. Es vender boletos. | booking / venta del show |

---

## Cuando el término aparece en boca ajena

Si un *promoter* o talento usa estos términos en una declaración que citamos
on-record, la dejamos textual y, si hace falta, comentamos por qué nos parece
sintomática. La blacklist es para **nuestra prosa**, no para censurar fuentes.

Ejemplo:
> Triple H habló de "construir una *season finale* hacia WrestleMania". El
> uso del léxico de TV es revelador: refleja la integración de la lógica
> Universal/streaming en el booking corporativo, y explica por qué el
> *go-home* dejó de tener filo carny.

---

*La lista crece cuando aparece un término que importa una gramática ajena,
y nunca por moda. No la usamos para correr a un lector: la usamos para
mantener la sustancia.*
