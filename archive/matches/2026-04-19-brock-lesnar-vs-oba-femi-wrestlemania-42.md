## Significancia editorial

- **Pass-over rub carny puro**: Brock como leyenda monstruo
  vuelve para legitimar a Femi como heel monster del periodo.
  Modelo old-school territorial transferido: el veterano
  trabaja con el ascendente y le da rub no via pin sino via
  **performance compartida en escenario máximo**.
- **Para el Vehemiurgo este es el formato correcto del return
  de leyenda**: no comeback championship recurrente, no main
  event monolítico. **Pass-over rub** al talent emergente. Si
  WWE booka esto bien, la era Brock-monolith termina con
  legacy intacto + talent nuevo elevado. **Booking ortodoxo
  carny old-school**.
- **Heyman como mánager parcial** + **contract signing 6 abr**
  + **promo video 10 abr** = build estructurado old-school.
  Heyman entiende exactamente cómo se construye un monster
  match.
- **Oba Femi como receptor del rub**: post NXT North American
  / NXT Champion run, Femi llega a main roster con físico +
  charisma sin promo verboso. **Modelo monster heel emergente**
  paralelo a Fatu. Carny ortodoxo de **doble monster heel
  building** en main roster simultáneo.
