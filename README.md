# El Vehemiurgo

Periodismo old-school de wrestling. Historiografía, opinión y archivo, desde
la trinidad **promotor / luchador / fan**.

> *La vehemiurgia es la liturgia del oficio: ortodoxia comunitaria, heterodoxia
> con fundamento, memoria histórica y vehemencia editorial.*

## Mapa del repo

| Carpeta | Qué vive ahí |
|---|---|
| [`CLAUDE.md`](./CLAUDE.md) | Doctrina y ley operativa del proyecto. Punto de partida obligatorio. |
| [`workflow.md`](./workflow.md) | Cómo trabajamos: pedidos, investigación, delegación, edición, publicación. |
| [`editorials/`](./editorials/) | Editoriales, manifiestos, columnas de opinión. |
| [`reviews/`](./reviews/) | Reviews semanales de shows (WWE, AEW, NJPW, etc.). |
| [`dossiers/`](./dossiers/) | Investigaciones largas: carreras, empresas, eras, ángulos, programas. |
| [`archive/`](./archive/) | Fact-sheets vivos por entidad: gente, empresas, programas, PPVs, eras, familias, contratos, entrevistas, podcasts. |
| [`templates/`](./templates/) | Plantillas para cada tipo de pieza. |
| [`glossary/`](./glossary/) | Léxico carny canónico y lista negra de términos prohibidos. |
